1. 如何使用 MESA 运行本课题参数空间？

                

                  第一步（初始化工作目录）：复制 $MESA_DIR/star/work 到本地项目目录，执行 ./mk 编译。

                  第二步（配置 inlist_project）：将左侧根据当前 (M₁, Z₁) 自动生成的配置保存为 inlist_project，执行 ./rn 启动一维流体静力学与核反应网络隐式牛顿-拉夫逊（Newton-Raphson）耦合求解。

                  第三步（导入看板对比）：将运行生成的 LOGS/history.data 直接点击右上角“📂 导入 MESA history.data”拖入本看板，即可与半解析网格轨线同屏叠加校验！
                

              

              

                
2. MESA 四大核心 Namelist 模块与物理映射

                

                  • &star_job：控制预主序模型生成（create_pre_main_sequence_model）与核反应网络切换（低/中质量星用 co_burn.net 追踪至碳氧核；大质量星用 approx21.net 追踪完整的 ¹H → ⁴He → ¹²C → ¹⁶O → ²⁰Ne → ²⁴Mg → ²⁸Si → ⁵⁶Fe 21 同位素链与光致蜕变）。

                  • &eos / &kap：控制状态方程（理想气体 + 辐射压 + HELM/Skye 电子简并态与正负电子对产生）及 OPAL Type 2 富碳氧变金属丰度不透明度表（use_Type2_opacities = .true.）。

                  • &controls：设定混合长理论参数 mixing_length_alpha、Ledoux 对流判据、指数对流超射 overshoot_f(1) 以及 Reimers/Blöcker（红巨星/AGB）与 Dutch（大质量星线驱动星风 Ṁ ∝ Z^0.65）质量损失方案。
                

              

              

                
3. MESA 输出文件结构：history.data vs profile*.data

                

                  • LOGS/history.data：按时间步（model_number, star_age）记录全星标量演化序列（对应本看板左上赫罗图与右上中心 ρ_c–T_c 相图）。

                  • LOGS/profile*.data：在特定演化时刻按内部质量网格点 q = m/M* 从表面到中心记录径向分布（对应左下 3D 洋葱皮剖切模型与右下径向丰度剖面 X_i(q)）。
                

              

            

          

        


        
        

          

            

              
✅ 原理修正 1：标准太阳模型 ZAMS 定标与“暗弱年轻太阳”效应

              

                原版将 1 M☉, Z=0.014 的零龄主序（ZAMS, t=0）光度直接设为 1.0 L☉ (T_eff = 5772 K)，混淆了零龄主序与当前 4.57 Gyr 太阳。随着主序核心氢聚变为氦，平均分子量 μ 从 0.61 增至 0.85，根据维里定理光度持续爬升约 40%。v2.0 修正为 ZAMS 从 L = 0.70 L☉ (log L = -0.155, R = 0.89 R☉, T_eff = 5600 K) 出发，在 t = 4.57 Gyr 精准穿过今日太阳定标点 ☉ (L = 1.0 L☉, T_eff = 5772 K)。
              

            

            

              
✅ 原理修正 2：大质量恒星辐射压与电子散射导致的质光关系展平

              

                原版对 2–25 M☉ 统一套用克莱默斯不透明度幂律 L ∝ M^3.5，导致 25 M☉ 光度虚高、主序寿命严重偏短。事实上在 M ≥ 10 M☉ 时，内部辐射压 P_rad = aT⁴/3 占主导，不透明度过渡为汤姆孙电子散射（κ_es），质光关系幂指数向爱丁顿极限展平（d log L / d log M ≈ 2.25–2.75），修正后 15 M☉ 与 25 M☉ 主序寿命恢复至 MESA 实测值（11.9 Myr 与 5.5 Myr）。
              

            

            

              
✅ 原理修正 3：0.3 M☉ 完全对流红矮星的均匀化学演化与蓝矮星转向

              

                原版将 0.3 M☉ 按 f_core = 0.10 计算并在 q = 0.15 处设置阶跃丰度边界。实际上 M ≤ 0.35 M☉ 恒星整颗处于完全对流混合态，对流时标远小于核反应时标，全星近 85% 的氢燃料均可参与聚变（寿命长达 ~787 Gyr），径向丰度剖面 X_i(q) 从中心到表面保持水平均匀，且氢耗尽末期因无壳层镜像膨胀效应而收缩升温为蓝矮星（Blue Dwarf），随后平稳冷却为氦白矮星。
              

            

            

              
✅ 原理修正 4：8 M☉ 临界恒星的金属丰度命运分岔与 MESA r24.03.1 兼容

              

                解决了原版文档宣称 M ≥ 8 M☉ 发生超新星坍缩、但代码却把 8 M☉ 全部算成白矮星的自相矛盾。v2.0 精确建模了 8 M☉ 超渐近巨星支（Super-AGB）的金属丰度分岔：在太阳/富金属（Z ≥ 0.014）下强 AGB 星风剥离包层留下 1.20 M☉ ONeMg 白矮星；而在极低金属丰度（Z ≤ 0.001）下弱星风使简并氧氖镁核增长至 1.37 M☉ 触发 ²⁰Ne/²⁴Mg 电子俘获超新星（ECSN）形成中子星！同时全面修复了 &kap 与 overshoot 的现代 MESA 语法。
